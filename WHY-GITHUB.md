# Why GitHub (short)

Netlify treats every upload as a **new whole site**. Dropping only `index.html` deletes the sign-in page, logos, and the access-code gate. That is why the code “stopped working.”

GitHub is the **one folder that is always complete**.

- Studio, sign-in, catalog, and gate files live together.
- Every change is a saved version. We can go back if something breaks.
- Netlify can publish **from the repo**, so we stop drag-and-drop.
- Sales, shop, and later the bot group work on the same files without emailing zips.
- The access code stays in Netlify settings — not in the repo.

**This is not extra process.** It is how we stop breaking the demo every time we update the door.
