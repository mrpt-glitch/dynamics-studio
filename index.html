Door size

Frame over slab = 2⅝″ on height. 6/8 = 79″ slab / 81⅝″ frame. 7/0 = 83″ / 85⅝″. 8/0 = 95″ / 97⅝″. A 3/0 slab is 35¹³⁄₁₆″ × 79″; the frame is 36″ × 81⅝″. Ticket prints both.

Rough opening

RO is jamb + ¾″ on width and jamb + ⅜″ on height. MO is jamb + 1¼″. Do not invent a “couple extra inches.”

RO sets unit size: width − 1″, height − ½″ − 1⅝″. Preview updates.
